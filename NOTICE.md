# Acknowledgements

Gothic II VR is a VR adaptation built on **OpenGothic**. The original engine
reimplementation was created by **Try and the OpenGothic contributors**.
Its world loading, game simulation, quests, dialogue, NPC logic and RPG systems
are their work. We do not claim to have created that engine from scratch.

This source snapshot uses **Solessfir's Android OpenGothic and Tempest forks**
as its baseline. Our changes add the standalone Quest OpenXR integration,
tracked VR interaction and combat, controller hands, VR menus, stereo rendering
and mobile rendering work.

- [Original OpenGothic](https://github.com/Try/OpenGothic)
- [Android OpenGothic baseline](https://github.com/Solessfir/OpenGothic)
- [Original Tempest](https://github.com/Try/Tempest)
- [Android Tempest baseline](https://github.com/Solessfir/Tempest)

The exact baseline revisions are retained in [config/source-lock.json](config/source-lock.json).
The included files contain local modifications and are not identical to those
upstream commits. [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json) identifies this
release snapshot by individual file hashes.

Original copyright notices and licenses remain in the source directories.
See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for dependencies.

No original game archives, scripts, dialogue, audio, video, levels, models,

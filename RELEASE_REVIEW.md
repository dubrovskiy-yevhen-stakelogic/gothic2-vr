# Release verification — 0.2.1



Release version: 0.2.1. Quest 3S feedback confirmed VRS, the correction for stationary TAA drift, and acceptable movement after removing animation-driven pulses. A complete playthrough and new PCVR gameplay validation remain outstanding.



The source snapshot includes the engine, Vulkan backend, all TAA/VRS shaders, controller and movement changes, regression tests, dependency locks, Quest build/install scripts and PCVR launchers. Retail game data, saves, personal INI files, signing keys, toolchain caches and local logs are excluded.



Host coverage includes 33 suites. Source archives carry a per-file SHA256 manifest and are extracted and audited without local-state exclusions. APK checks cover package/version identity, signature, ARM64 layout, assets and Android lint. The current release-build verification records accompany the packaged artifacts.



Source comments and release prose were reviewed for conversational notes and placeholder text. Required protocol values, third-party identifiers, copyrights and license text are retained.
